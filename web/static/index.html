SSL certificates

Get a new certificate

Let's Encrypt / ZeroSSL via acme.sh, auto-renewing.

Import an existing certificate

Paste your cert & key — it's validated, stored and applied into the panel's own folder.

Apply a stored certificate to a panel

Certificates are copied into a folder the panel & its Docker container can read (/var/lib/<panel>/certs/<domain>/), the panel's SSL config is pointed at them, and the panel is restarted. Renewals re-apply automatically. Point the domain's A/AAAA record here first.
